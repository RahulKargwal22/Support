BACKENDPowered by Google Apps Script

How the Slack app is built, step by step

Create the Slack app. Register “GIC Support” in the Slack API console, set its name and icon, grant the required permissions, install it to the workspace and keep its bot token as a secret.
Bind a script to the Google Sheet. The Sheet is the analyst's workspace and Apps Script is the serverless backend, so there is no server to host. The token is kept in Script Properties.
Add the menu. An onOpen trigger builds the “GIC Support Assistant” menu.function onOpen(){ SpreadsheetApp.getUi().createMenu('GIC Support Assistant') .addItem('Send to All Pending Cases','sendAllPending') .addItem('Send to Single Case','sendSingle') .addItem('Bulk Acknowledgment','bulkAck').addToUi(); }
Call Slack from the script. UrlFetchApp posts to the Slack Web API (chat.postMessage) with the bot token, so the message appears as “GIC Support”.UrlFetchApp.fetch('https://slack.com/api/chat.postMessage',{ method:'post', headers:{Authorization:'Bearer '+TOKEN}, contentType:'application/json', payload:JSON.stringify({channel:channelId,text:message})});
Write results back. STATUS, SENT_AT, SENT_BY, ERROR and MESSAGE_LINK are written to the row, so failures are visible and retries are safe.
